CÁCH ĐƯA LÊN GITHUB TỪ REPO NÀY
Chạy tại thư mục HocSau-python_Git (không chạy từ thư mục BTL03 bên trong):
  git status
  git log -1 --oneline
  git push -u origin XuanAnh
Lần bàn giao này dùng trực tiếp XuanAnh, không cần tạo nhánh feature khác.
Cấu trúc được tích hợp từ Nhi; lịch sử XuanAnh cũ được giữ bằng commit mới,
không cần force-push hoặc xóa lịch sử.
